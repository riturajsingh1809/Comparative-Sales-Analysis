# Comparative Sales Analysis

*Developed by Ritu Raj Singh*

## Project Overview

This project focuses on comparative sales analysis to identify performance differences across regions, plans, channels, and months.

## Tools Used

* *Excel* – Data cleaning and data preparation
* *Python (Pandas)* – Data analysis and comparative insights
* *Tableau* – Data visualization and dashboard

## Data Cleaning

The raw dataset was cleaned and prepared using *Microsoft Excel*. The cleaning process included handling missing values, removing duplicates, standardizing data, and preparing the dataset for analysis.

## Analysis

Python was used to calculate overall sales, profit, units, average sales, and comparative performance across different regions, plans, channels, and months.

## Dashboard

The final visualizations and interactive dashboard were created in *Tableau*.

## Files

* Cleaned_Dataset.xlsx – Cleaned dataset
* Analysis_Result.xlsx – Python analysis results
* Comparative_Sales_Dashboard.twbx – Tableau workbook
* README.md – Project documentation

## Conclusion

The project provides comparative insights into sales performance and helps identify the segments contributing most to the overall results.
